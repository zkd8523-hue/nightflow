# NightFlow English blog — writing rules (internal, not published: files starting with _ are skipped)

Audience: foreign travelers (mostly English-speaking, many from SE Asia/US/EU) planning a night out in Korea. They arrive from Google with one concrete question.

## Facts
- Only facts you verified in this task, with the source noted in your research notes. NightFlow's own pages (nightflow.kr/en/...) count as a source for club names, areas, music, hours, prices shown there.
- Never invent prices, opening status, dress rules, door policies or numbers. If you could not verify, say so briefly or leave it out.
- Closed/renamed venues: state status only if a dated news source or official notice confirms it; give the date.
- No pub crawls. No hostess bars / room salons. No drug or sexual-service references.

## Structure (Google, not Naver)
- Front matter (exact keys): title (≤ 65 chars, main keyword first), h1, description (140–160 chars), date, updated, cta (one sentence above the booking button), related (2–4 lines, `related: /en/... | Label`, only URLs that exist on nightflow.kr/en).
- First 2–3 sentences answer the searcher's question directly (no "In this article…", no greetings).
- `##` sections that each answer one sub-question; `###` only when needed. Short paragraphs (2–4 sentences). Use one comparison table where it helps choosing.
- Link to existing NightFlow pages inline where relevant (/en/clubs/hongdae, /en/clubs/itaewon, /en/clubs/gangnam, /en/clubs/busan, /en/dress-code, /en/club-entry-rules, /en/club-prices, /en/club-hours, /en/night-activities/getting-around, /en/vip-tables, /en/guests, /en/hiphop-clubs, /en/kpop-clubs). Don't copy their text.
- Sources: a short "Sources" line at the end with external official/news links used (markdown links).
- 900–1,600 words. Plain, friendly, confident English. No emojis in body. No fluff, no clichés ("vibrant", "bustling", "hidden gem", "look no further").
- Booking is handled by the page template (button after the article); in the body mention NightFlow booking at most once, naturally.

## Markdown allowed
`##`, `###`, paragraphs, `- ` lists, `1. ` lists, tables with `|`, `**bold**`, `[text](url)`, `> quote`. Nothing else (no images, no HTML).
