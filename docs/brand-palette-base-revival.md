# 베이스 팔레트 개정 — 순흑 → 딥 남보라

> **목적**: "밤을 더 아름답게" 중 **Legitimacy(양지화) 배반**을 정조준한다.
> 순수 무채색(채도 0) 베이스는 "밤의 깊이"가 아니라 "전원 꺼짐"의 색이다.
> 밝기(L)는 그대로 두고 **채도(C)만 미세하게 주입**해, 어둠을 죽이지 않으면서 살린다.
>
> **범위**: 베이스/카드/섹션 배경 + 보더 **3~4개 토큰만**. 포인트색(amber/green/pink/blue)·온기분리·네온글로우는 **이번 범위 아님**(다음 기회).
>
> **작성일**: 2026-06-02 · **상태**: 팔레트 문서(구현은 별도 지시)

---

## 1. 설계 원칙 (왜 이렇게 하는가)

1. **명도 불변(L 고정)** — 기존 `oklch(0.145 0 0)` → `oklch(0.145 0.018 285)`. 세 번째 값(채도)만 `0 → 0.018`. **밝기는 1도 안 바뀌므로 대비·가독성·FOMO 영향 0**.
2. **저채도 유지** — 채도 0.015~0.022. 사람이 "보라다"라고 인지하기 직전의 경계값. 화면은 여전히 "검정처럼 보이는데, 묘하게 깊다"가 목표. 보라 클럽앱이 되면 실패.
3. **색상(Hue) = 285° (남보라)** — 밤하늘·새벽의 색. 자홍(330°)은 너무 유흥, 순파랑(250°)은 너무 차가움. 285°가 "깊고 따뜻함이 살짝 도는 밤".
4. **OKLCH 우선, HEX는 폴백** — globals.css가 이미 OKLCH라 토큰만 교체하면 됨. HEX는 하드코딩된 `bg-[#...]` 교체용 참고값.

---

## 2. 토큰 매핑표 (Before → After)

| 토큰/용도 | 현재 (무채색) | 개정안 (딥 남보라) | HEX 근사 | 명도 변화 |
|---|---|---|---|---|
| `--background` 페이지 배경 | `oklch(0.145 0 0)` | `oklch(0.145 0.018 285)` | `#0C0A14` | **없음** |
| `--card` 카드 배경 | `oklch(0.205 0 0)` | `oklch(0.205 0.016 285)` | `#16131F` | **없음** |
| 섹션 구분 배경 | `#111111` (하드코딩) | `oklch(0.17 0.017 285)` | `#100E18` | **없음** |
| 순흑 배경 | `#0A0A0A` (하드코딩) | `oklch(0.135 0.018 285)` | `#0A0810` | **없음** |
| `--border` 보더 | `oklch(1 0 0 / 10%)` | `oklch(0.8 0.04 285 / 12%)` | — | 미세 |

> **읽는 법**: `oklch(L C H)` = 명도(0~1) · 채도 · 색상각(°). 세 토큰 모두 L은 현재와 동일, C만 0→0.016~0.018, H=285 추가.

## 3. Tailwind 토큰화 제안 (하드코딩 정리)

현재 `#1C1C1E`가 **111개 파일**에 하드코딩됨 → 색을 한 곳에서 관리할 수 없는 게 진짜 병목.
이번에 시맨틱 토큰을 도입하면 다음 개정 때 한 줄로 끝남.

```ts
// tailwind.config.ts → theme.extend.colors
colors: {
  // 밤 베이스 (deep navy-violet, 명도는 기존과 동일)
  night: {
    base:    'oklch(0.135 0.018 285)',  // 구 #0A0A0A
    page:    'oklch(0.145 0.018 285)',  // 구 --background
    section: 'oklch(0.17  0.017 285)',  // 구 #111111
    card:    'oklch(0.205 0.016 285)',  // 구 #1C1C1E / --card
  },
}
```

```css
/* globals.css :root.dark — 변수만 교체, 나머지 그대로 */
--background: oklch(0.145 0.018 285);
--card:       oklch(0.205 0.016 285);
--border:     oklch(0.8 0.04 285 / 12%);
```

## 4. 적용 우선순위 (구현 시 순서)

| 순위 | 대상 | 효과 | 리스크 |
|---|---|---|---|
| **1** | `globals.css` `--background` / `--card` 변수 교체 | 변수 쓰는 모든 화면 자동 적용. **가장 큰 효과/최소 작업** | 거의 없음 (L 불변) |
| **2** | 하드코딩 `bg-[#0A0A0A]` → `bg-night-base` | 홈 hero·HotDeal 배경 | 낮음 |
| **3** | 하드코딩 `bg-[#1C1C1E]` → `bg-night-card` (111개) | 전 카드 통일 + 향후 관리 용이 | 낮음(일괄치환) |
| **4** | `--border` 미세 채도 | 경계선도 같은 밤 톤으로 | 낮음 |

> 1번만 해도 화면의 80%가 바뀐다. 2~3번은 일괄치환(sed) 가능하나 별도 지시 시 진행.
