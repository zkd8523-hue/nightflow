select utm_campaign, count(*) from foreign_requests

```

## 3. 🔑 SEO에 쓸모 있는 부분 — 키워드 실측

7개 시장을 Google 키워드 플래너 + 네이버 키워드도구로 **직접 조회**했다. 추측 아님.

### 국내 (네이버, 월간 PC+모바일)

| 키워드 | 검색량 | 경쟁 | 클릭률 |
|---|---|---|---|
| 홍대클럽 | **9,410** | 높음 | 0.06% |
| 강남클럽 | **4,170** | 높음 | 0.06% |
| 클럽MD | 580 | 중간 | 0% |
| 클럽테이블 | 100 | 높음 | 0.84% |
| 클럽예약 | **30** | 낮음 | 0% |

**국내 2개 키워드(1.36만)가 해외 6개 시장 전체(2.7만)의 절반.** 클릭률이 0.06%로 극히 낮은 게 특징 — 광고가 3개 붙어 있는데 아무도 안 누른다. 정보 보러 온 사람이지 광고 보러 온 게 아니라는 뜻이고, **SEO로 먹기 좋은 자리**라는 신호이기도 하다.

### 🔴 SEO 전략에 직접 영향 주는 발견 3가지

**(1) 예약 의도 검색은 어디에도 없다**

7개 시장에서 각각 다른 방법으로 확인했는데 전부 0이었다.
- 영어권: book/reservation/booking 계열 8개 전부 0 (`seoul bottle service`, `seoul vip table` 포함)
- 일본: `クラブ 予約` 씨앗 → 265개 전부 골프장·리조트 예약 (일본어 `クラブ`는 골프장 뜻)
- 대만: `訂位` 붙은 검색어 0
- 국내: `클럽예약` 월 30

→ **수요가 없어서가 아니라 카테고리가 없어서다.** 한국은 MD 인프라가 이미 깔려 있고 예약은 인스타·전화가 표준이라 "예약 사이트"라는 개념 자체가 없다. 나이트플로우가 최초.
→ **이 카테고리를 만드는 건 SEO·콘텐츠의 일이다.** 검색광고는 기존 수요를 가로채는 도구라 못 만든다.
→ 관찰 지표: 네이버 `클럽예약` 월 30(2026-09 기준). 이게 늘면 카테고리 형성 신호.

**(2) 사람들은 "클럽 이름"을 직접 검색한다**

영어권·중동·일본 조회에서 공통으로 나온 패턴:
```
octagon seoul / club face seoul / club made seoul / b1 club seoul hongdae
club avenue 535 seoul / aura club hongdae / four seasons seoul club lounge
オクタゴン ソウル / ハミルトン ホテル 梨泰院 クラブ
```
개별 볼륨은 10~100으로 작지만 **개수가 매우 많고(영국 205개, UAE·사우디 각 251개) 의도가 명확하다.**

→ 이런 롱테일은 광고로 하나씩 사는 게 비효율적이다. **클럽 상세 페이지 SEO가 정답.** 클럽 페이지 59개가 이미 색인돼 있으니 영문·일문 클럽 상세를 강화하면 광고비 0원으로 이 트래픽을 가져올 수 있다.

**(3) "외국인 친화"를 명시적으로 검색한다**

중동·영어권에서 반복 등장:
```
clubs for foreigners in seoul / foreigner friendly clubs in gangnam
best clubs in seoul for foreigners / gangnam club foreigners / busan nightlife foreigners
韓國 夜店 穿著 (드레스코드) / 韓國 夜店 推薦 (추천)
```
나이트플로우 가치제안과 정확히 일치한다. `/zh-tw/dress-code` 같은 정보 페이지가 이미 있으니 이 검색어를 노린 콘텐츠 보강이 유효하다.

### 지역 우선순위 (검색량 기준)

```
홍대·이태원 > 강남    (영어권 기준 10배 차: 홍대/이태원 100~1천 vs 강남 10~100)
부산은 서울과 같은 자릿수 (일본·대만 모두 釜山 클럽 100~1천)
```
⚠️ 이태원은 승인 클럽 30개로 **강남(19개)보다 많고 예약도 열려 있다**(`OPEN_FLAG_AREAS`에 2026-07-08 추가됨). 7월 초 "Coming soon" 기록만 보고 제외 대상으로 오판했던 이력이 있으니 주의.

## 4. 조회 시 함정 (다음에 또 헤매지 말 것)

- **"성인용 아이디어 제외" 필터가 기본 ON** — 클럽/나이트라이프가 성인 카테고리로 분류돼 결과가 대량 누락. 반드시 끌 것
- **위치·언어를 현지로 안 바꾸면** 결과가 거의 안 나옴. 대만은 반드시 **번체**(간체로 하면 0개)
- **씨앗 난이도**: 너무 구체적(`ソウル クラブ`)이면 확장 0, 너무 넓으면 엉뚱한 게 옴
  - 일본어 `クラブ`=골프장/회원제, `オールナイト`=라디오 프로그램, `イベント`=포켓몬. `韓国 クラブ` 정도가 적정
- **CPC는 "최저범위"를 볼 것.** 최고범위는 1등 입찰가라 실제와 무관
- 기존에 인용하던 CPC $2.1(2,900원)은 여행업종 평균이라 **약 7배 과대**였음. 실제는 수백원대

```

캠페인 상태 경고는 전부 무해:
- "관련성 높은 키워드가 충분하지 않음" → 실측으로 검증된 8~10개만 넣은 의도된 상태
- "새 입찰 전략이 학습 중" → 새 캠페인이면 항상 뜸
- `tw_hk_test` "주류 정책 제한" → 주류 광고 금지 국가에서만 제한. 대만·홍콩·한국은 모두 허용이라 실제 영향 없음

**판단 기준**: 전환율 2% 이상이면 예산 증액, 1% 미만이면 해당 시장 중단.

**참고**: 검색량 천장 때문에 전 세계 다 합쳐도 **월 광고비 54만원 이상 쓸 수가 없다.** 최악의 경우가 "54만원 태우고 0건"이라 리스크가 한정적인 대신, 주력 채널은 될 수 없는 구조다. 그래서 SEO가 여전히 본진.
