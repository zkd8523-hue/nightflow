# 🔥 부산 200명 야외 무알콜 음악행사 — 장소·섭외 정리

> 컨셉: **무알콜 + DJ + 화로대(불멍) + 푸드트럭 + 자유로운 파티**. 도심 접근성 중시.
> 브랜드 커뮤니티 모임 + 콘텐츠 촬영 겸용. "술 없이, 모닥불 앞에서, 음악에 춤추는 밤" = 밤문화 편견 정면 반박.
> ※ 리서치 3차례 교차검증(2026-06-24). 대부분 "확인필요" = 실제 견적은 직접 문의.
> ⚠️ 이 행사 ≠ Song for Love(어르신 디제잉 기부). 별개 이벤트. [[project_song_for_love]] 참조.

## ⚠️ 핵심 결론 (검증이 깬 환상)
1. **"파티 OK 캠핑장"은 사실상 없음** — 부산·경남 캠핑장 거의 전부 정숙(22~05시 소음금지)이 기본. DJ 틀면 퇴실.
2. **"공개 대관하는 옥상주차장"도 부산엔 없음** — 공개 루프탑은 다 수십 명 파티룸. 200명+무대+푸드트럭+화기는 직접 섭외.
3. **캠프파이어 직화는 거의 어디든 불가** — 옥상·문화시설 특히. **화로대도 소방 사전협의**. 평면 노지가 그나마 유리.
4. **22시 이후 옥외 음악 = 고위험** (야간 생활소음 60dB). → **"낮(점심~오후) 타임"**이 답 (무알콜·건강한 밤 컨셉과도 맞음).
