# 캐러셀 #1 이미지 핸드오프 — "왜 우리는 클럽에서 살아나는가"

> **수신**: 프롬프트 담당 (별도 프롬프트 채팅방에서 실제 프롬프트 작성)
> **발신**: 콘텐츠 기획
> **요청**: 아래 10장 각각에 들어갈 배경 이미지를 우리 고정 스타일로 생성

---

## 0. 반드시 지킬 고정 규칙 (메모리: AI 이미지 프롬프트 스타일)

- **베이스 철학**: Candid documentary + sweaty raw chaotic. `glossy`/`luxury`/`polished`/`smooth amber`/`cinematic 단독` 금지.
- **필수 키워드 세트**: `vivid Kodak Portra 400 film` / `sweaty flushed skin` / `visible film grain` / `dominant pink magenta neon glow` / `lightly blurred crowd, faces readable` / `raw documentary atmosphere`
- **장소**: Hongdae underground club, Seoul (저천장·노출벽돌·UV블랙라이트·그린레이저). 일부 장은 강남 가능.
- **비율**: 전부 **세로 4:5 (`--ar 4:5`)** — 인스타 캐러셀.
- **★이번 톤 조정(중요)**: 이 캐러셀은 Jackass 웃긴 톤 ❌ → **진지·감성·몰입(transcendent)** 무드. 단, raw·grain·sweaty 텍스처는 그대로 유지. 표정은 "exhausted + transcendent / 평온 / 황홀 / 진지". 과장 goofy 표정 금지.
- **텍스트 공간**: 각 장 위에 흰 글씨 한 줄이 올라감 → **프레임 상단(또는 지정 위치)을 어둡게 비워둘 것**. 인물/군중은 화면 아래나 한쪽으로.

## 2. 시리즈 연출 포인트 (프롬프트 담당 참고)

- **6장 ↔ 9장 대비가 핵심**: 6장은 "혼자=고립", 9장은 "군중 속 연결". 가능하면 **같은 인물/같은 옷차림**으로 찍어 '혼자였던 사람이 연결되는' 서사를 시각적으로. (안 되면 무드 대비만으로도 OK)
- **감정 곡선**: 1~5장은 개인의 몰입(차분·황홀) → 6장 반전(고립) → 7~8장 집단 환희(가장 밝고 따뜻) → 9장 연결(뭉클) → 10장 여운.
- **색 온도**: 핑크 마젠타 네온 베이스 유지하되, 8장(집단열광)을 가장 따뜻하게, 6장(고립)을 가장 차갑게 미세 조정.
- **인물**: 20-30대 한국인. 특정 1~2인 집중 장면(2,3,5,6,9)과 군중 와이드(1,7,8,10) 교차.
