# NightFlow 서브타이틀 카피 후보 정리

## 비전
> **"클럽을 더 많은 사람들이, 더 저렴하게, 더 편하게 즐긴다"**

핵심 = 대중화 (Mass Market) + 가격 절감 + 진입 편의

## 평가 기준
| 차원 | 의미 |
|------|------|
| 임팩트 | 기억성, 차별화, 클럽 톤 정합 |
| 약속 명확 | 유저에게 뭘 약속하는지 0.5초 안에 이해되는가 |
| 비전 정합 | 많이/저렴/편하게 중 몇 개 담는가 |

## 토론에서 도출된 핵심 인사이트

### 1. "가격 결정권"은 USP가 아니다
"내가 가격을 정해" 류 카피는 카피라이팅 함정.
→ 소비자는 원래 안 사면 그만. **공허한 약속.**
→ 진짜 USP는 "결과적으로 가격이 내려간다" + "원래 못 가던 곳을 간다".

### 2. "가장 OO한 플랫폼" 포맷은 광고로는 약함
- 형용사 하나에 약속이 갇혀서 함축적
- 1차 욕구(재미, 분위기, 가격) 직접 자극 X
- 신생 브랜드가 "가장"을 외치면 신뢰 부족
- 검색·SEO엔 유리하지만 카피로는 한계

### 3. VIP 프레임은 비전과 충돌
- 비전: 대중화 (Mass)
- VIP: 엘리트 (Niche)
- 둘 다 거짓이 되는 모순. 단, **"누구나 VIP처럼"** 같은 반전형은 OK.

### 4. "솔직한" / "강력한"은 약속이 모호
- "솔직" = 뭐가 솔직한지 명시 필요 (가격? 정보? 후기?)
- "강력" = 임팩트는 강한데 약속 공허
- → 광고 카피보단 6개월 후 미션 스테이트먼트 용도가 적합

### 5. 1차 욕구를 직접 자극해야 한다
유저의 욕구 순위:
- **1차**: 재미, 싸게, 편하게, 분위기 ← 광고가 이걸 직격해야 함
- **2차**: 사기 안 당하기, 합리적 소비 ← 사용 후 느끼는 가치

→ "비싸서 못 갔던" / "만만해진다" 같은 **결과·변화 약속**이 강함.
